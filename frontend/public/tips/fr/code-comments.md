---
title: "Commenter des lignes de code"
platform: [desktop]
---

Dans toute vue de code ou de différences — modification dans la discussion, onglet Fichiers ou commit Git — survolez un numéro de ligne et cliquez sur le **+** dans la marge pour annoter cette ligne.

Vos notes apparaissent comme indicateurs sur les messages et commits concernés. **Ajouter au message** insère le commentaire et sa ligne dans la zone de saisie ; vous pouvez aussi tout ajouter ensemble.
