---
title: "Rechercher dans une session : Cmd+F"
platform: [desktop]
os: [mac]
---

Appuyez sur **Cmd+F**, ou cliquez sur la loupe de l’en-tête, pour rechercher dans la conversation actuelle. Cette recherche remplace celle du navigateur ; appuyez de nouveau sur **Cmd+F** pour utiliser celle du navigateur.

**F3 / Maj+F3** parcourt les correspondances et **Échap** ferme la recherche. Pour toutes les sessions, utilisez **Cmd+Maj+F**.
