---
title: "Démarrer une session dans un nouvel arbre de travail"
---

Ouvrez **Nouvelle session** : les projets Git affichent un bouton d’arbre de travail (branche avec un **+**). Il crée un arbre de travail sur une branche nouvelle ou existante et y ouvre une session.

L’arbre de travail est associé automatiquement au projet parent ; ses sessions sont regroupées sous le dépôt principal.

Consultez [Travailler avec les arbres de travail](help/worktrees).
