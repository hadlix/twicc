---
title: "Approuver vos projets"
---

Claude Code et Codex gèrent chacun la confiance des projets. TwiCC centralise cette décision : au premier démarrage dans un projet, il vous interroge, enregistre le choix pour les deux fournisseurs et peut l’appliquer aux sous-dossiers et arbres de travail.

Les projets commencent non approuvés ; les modes d’accès complet restent alors bloqués (contournement de Claude, YOLO de Codex). Choisissez le mode des projets non approuvés dans les paramètres du fournisseur, par exemple la lecture seule. L’accès complet devient disponible lorsque vous approuvez le projet.
