---
title: "Travailler avec les projets"
---

Un projet est un **dossier de travail** où s’exécutent les sessions des agents : un projet par dossier. TwiCC en crée automatiquement pour les dossiers contenant des sessions, y compris celles de Claude Code ou Codex exécutées **en dehors** de TwiCC. Vous pouvez aussi ajouter un projet en indiquant son dossier.

### Contenu d’un projet

Toutes les sessions exécutées dans ce dossier sont regroupées sous le projet, pour retrouver votre travail selon son emplacement.

### Ouvrir un projet

Ouvrez l’**accueil** du projet depuis la page d’accueil ou le sélecteur en haut du panneau latéral, même s’il est déjà sélectionné. Dans une session, cliquez sur le nom du projet dans l’en-tête pour y revenir.

Pour renommer le projet ou modifier ses réglages, ouvrez son menu **⋮** sur l’accueil ou dans le sélecteur et choisissez **Modifier**.

### Personnalisation

Définissez un **nom**, une **couleur** et des **réglages par défaut propres au projet** (fournisseur, paramètres de l’agent, disposition) pour ses nouvelles sessions.

Les projets **nommés** apparaissent en haut de l’accueil sous forme de cartes. Les projets **sans nom** sont listés en dessous dans une arborescence de dossiers.

### Organisation

Regroupez les projets liés dans un [espace de travail](help/workspaces). Les [arbres de travail Git](help/worktrees) apparaissent comme des projets distincts associés au dépôt principal. La vue du projet principal regroupe aussi leurs sessions, avec un indicateur pour les distinguer.

### Archivage

Un projet terminé peut être **archivé** : il disparaît des listes, sans suppression, et ses sessions restent recherchables. Archivez-le depuis sa fenêtre de modification ou son menu **⋮** dans le sélecteur. Pour le retrouver, cochez **Afficher les éléments archivés** dans la section Projets de l’accueil, puis **désarchivez-le** si nécessaire.
